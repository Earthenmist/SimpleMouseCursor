
# Simple Mouse Cursor

A lightweight, standalone addon that enhances cursor visibility during gameplay by displaying customizable rings, indicators, and optional effects around your mouse cursor.  
Originally based on a popular WeakAura concept, rebuilt from scratch as a more performant and reliable addon with **zero dependencies**.

## ✨ Features

### 🔵 Core Cursor Rings
- **Main (Middle) Ring** – Always-visible cursor highlight  
- **Inner Ring** – Global cooldown progress  
- **Outer Ring** – Casting/channeling progress  
- **Cursor Trail** – Optional animated trail following cursor movement  

### 🎨 Customization
- Class-colored:  
  - GCD ring  
  - Main ring  
  - Cast ring  
  - Cursor trail  
- Power-type color option for the power ring  
- Adjustable:  
  - Trail density  
  - Trail duration  
  - Trail scale  
  - Cursor ring scale  
  - **Frame strata (layering)**  

### 🎯 Reticle Options
- Multiple styles: dot, chevron, crosshair, ring, X, diamond, and more  
- Adjustable reticle size  
- Optional class-colored reticle  

### 👁 Visibility Controls
- Show rings only while in combat  
- Modifier-based actions (Shift, Ctrl, Alt), each configurable:  
  - Show Rings  
  - Ping with Ring  
  - Ping with Area  
  - Ping with Crosshair  
  - Show Crosshair  

### 🧭 Compatibility
- **The War Within (Retail)**  
- **Midnight Beta** (GCD, Health, and Power tracking temporarily disabled)  
- Works with all UI replacements  
- Resolution-independent (supports 1080p → 4K+)

## 📦 Installation

### Manual Installation
1. Download the latest release from the **Releases** page.  
2. Extract the folder **SimpleMouseCursor**.  
3. Place it in:  
   ```
   World of Warcraft\_retail_\Interface\AddOns\
   ```
4. Restart WoW or reload UI (`/reload`).

---

## ⚙️ Configuration

Open options in-game:  
  
```
Esc → Options → AddOns → Simple Mouse Cursor
```

All settings update instantly:
- Ring selection  
- Colors  
- Trail properties  
- Modifier actions  
- Visibility  
- Reticle type, scale, color  
- Frame strata  
- And more  

No reload required.
