## 🧩 Addon Updates (2026-02-10)

**Simple Mouse Cursor** — v1.1.0  

**Changes:**  
- Added Pulse Feature Request from Discord.  
  - Added the ability to flash the main ring between two colors to make it more visible (default is off)  
  - Disabled Use Class Color for Main Ring if Enable Main Ring Pulse is Selected
  - Provided Color pickers for both pulse colors and a slider for the opacity of each color (Disabled if Main Ring Pulse is Not Selected)
  - Slider to adjust the pulse speed (Disabled if Main Ring Pulse is Not Selected)
- Added Rotation Feature Request from Discord.  
  - Added the ability to rotate the main ring with two colors to make it more visible (default is off)  
  - Disabled Use Class Color for Main Ring if Enable Main Ring Rotation is Selected
  - Provided Color pickers for both Rotation colors and a slider for the opacity of each color (Disabled if Main Ring Rotation is Not Selected)
  - Slider to adjust the Rotation speed (Disabled if Main Ring Rotation is Not Selected)
- Updated to v1.1.0 as new features added

**Fixes:**  
- None.

**Known issues:**  
- None currently known.
