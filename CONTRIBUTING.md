# Contributing

Thanks for taking the time to contribute! ❤️  
Bug reports, fixes, and improvements are always welcome.

This repository is **All Rights Reserved**, but contributions are still encouraged via GitHub Issues and Pull Requests.

---

## 📌 Quick Rules (Please Read)

You MAY:
- Submit bug reports and feature requests
- Fork this repository for development and testing
- Submit Pull Requests back to this repository

You MAY NOT:
- Reupload or redistribute this addon (or any modified version) on CurseForge, Wago, GitHub Releases, addon managers, or “UI packs”
- Publish “fixed versions” of this addon as separate projects without explicit permission

If you’ve fixed something — awesome. Please open a PR so the fix can be included in the official release.

---

## 🐛 Reporting Bugs

When reporting a bug, please include:

- What you were doing
- What you expected to happen
- What actually happened
- Steps to reproduce (numbered)
- Addon version
- Full Lua error text (if applicable)
- Screenshots (if UI-related)

---

## 💡 Feature Requests

Feature requests are welcome — especially if they improve usability, performance, or compatibility.

Please include:
- The problem you’re trying to solve
- What you’d like the addon to do
- Any screenshots or examples (if relevant)

---

## 🔧 Development Setup

1. Clone the repository
2. Copy or symlink the addon folder into your WoW AddOns directory:

   `World of Warcraft/_retail_/Interface/AddOns/`

3. Reload the UI (`/reload`) or restart WoW
4. Test your changes in-game

---

## ✅ Pull Request Guidelines

Before opening a PR:

- Keep PRs focused (one fix/feature per PR where possible)
- Avoid unnecessary refactors unless they are required
- Test the change in-game
- Make sure there are no Lua errors
- If you changed UI elements, include screenshots

---

## 🧪 Testing Notes

Please test in:
- Normal open world gameplay
- At least one instance/raid scenario (if relevant)
- Combat lockdown situations (if the addon interacts with UI elements)
